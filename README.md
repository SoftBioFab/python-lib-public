# python-lib-public

Small Python scripts for data and image analysis. Each folder contains one script with its own README.

| Folder | Description |
|---|---|
| [msd-random-walk](msd-random-walk) | 2D random walk simulation, MSD with errors, fit of the diffusion coefficient |

## Setup

Requires Python 3.9+ and the packages in `requirements.txt`:

```
pip install -r requirements.txt
```

Run a script from its folder. Figures are saved in that folder's `figures/` subfolder.
